Make a simple favicon PNG (32×32)

FastImageTool is not a favicon generator with all ICO sizes. You can still make a small PNG tab icon here.

  1. Start from a square logo. If it is not square, center-crop to equal width and height first.
  2. Open Image Resizer and set width and height to 32 or 64.
  3. Download PNG. Put it on your site as /favicon.png and link it with <link rel="icon" href="/favicon.png">.

Windows .ico with multiple sizes needs a desktop tool. Browsers accept PNG favicons.
