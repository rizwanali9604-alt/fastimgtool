JPEG compression settings we actually use

This is not a survey of TinyPNG, Squoosh, AVIF, or “AI compressors.” FastImageTool’s compressor runs in a Web Worker in your browser. It accepts one image. JPEG quality is a trade: smaller file, some detail gone.

Defaults that work for sellers

  • Format: JPEG for Meesho/Amazon catalog shots. WebP if the destination is a modern website. PNG only when you need transparency.
  • Quality: start at 85%. Drop toward 75% only if the file is still over the marketplace cap (Meesho: stay under 2MB unless the Supplier Panel says otherwise).
  • Max longer side: 2048px is the compressor default for web and email. Use 600 after the resizer for Meesho squares.

What we do not do

  • No AVIF export.
  • No folder / zip batch.
  • No claim of zero quality loss on JPEG.

Keep a master original on disk. Compress a copy. For Gmail attachment math see Compress for email.
