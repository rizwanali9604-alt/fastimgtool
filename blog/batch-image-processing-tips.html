Catalog photos one by one (we do not batch-process)

FastImageTool does not upload a folder of images and process them all at once. Each tool accepts one file per visit. If you have 80 SKUs, you repeat the same steps 80 times. This article is the honest workflow, not a fake “batch uploader.”

Why we stay one-at-a-time

Processing runs in your browser so catalog photos never hit our servers. A true batch engine would either upload files or need a desktop app. We chose local, private, single-file tools.

A repeatable seller loop

  1. Keep master originals in a folder on disk. Never overwrite them.
  2. Open Image Resizer. Use Meesho 600×600 or Amazon 1000×1000 (or type exact pixels).
  3. Open Image Compressor. JPEG, quality around 85%, until the file is under the platform cap (Meesho: under 2MB unless the Supplier Panel says otherwise).
  4. Save with a SKU in the filename. Repeat for the next photo in the same tab.

For true bulk (hundreds of files overnight), use a local tool such as ImageMagick or a desktop editor. Then you can still use FastImageTool for one-off marketplace rejects.

What not to expect here

  • No multi-file dropzone.
  • No zip download of a whole catalog.
  • No Photoshop Actions or Lightroom presets.
