JPG, PNG, WebP, HEIC — formats we actually convert

Use the upload hint on each tool page. This table is the short version.

FormatOn this site
JPEG / JPGDefault for catalogs. Lossy. No alpha channel.
PNGKeeps transparency if the source had it. Larger files. JPG→PNG does not invent transparency.
WebPOften smaller for websites. Some marketplaces still want JPEG. See WebP vs JPG.
HEICHEIC to JPG via a browser library. Not every iPhone file will decode.
GIFGIF to PNG exports the first frame only — not a full animation.
TIFF / BMPConverters exist for scans and old bitmaps. Output is JPEG for listings, not “print quality.”

We do not export AVIF. For marketplace vs website choice, read the WebP vs JPG guide rather than a second copy of that article.
